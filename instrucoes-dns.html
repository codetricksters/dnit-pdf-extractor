🌐 Configurar Acesso por Nome

Configure seu computador para acessar http://reequilibrio.local

📋 Como Funciona

Para que seu computador consiga acessar http://reequilibrio.local, ele precisa saber que esse nome aponta para o IP 192.168.10.20.

Você precisa configurar seu computador (ou o roteador) para usar 192.168.10.20 como servidor DNS.

⚙️ Opção A: Configurar no Roteador (Recomendado)

Vantagem: Afeta todos os dispositivos da rede automaticamente.

  1. Acesse o painel do roteador (geralmente 192.168.1.1 ou 192.168.0.1)
  2. Entre com usuário e senha do roteador
  3. Procure por "DHCP", "DNS" ou "Configurações de Rede"
  4. Configure o DNS Primário como: 192.168.10.20
  5. Salve as configurações
  6. Reinicie o roteador
  7. Reconecte seus dispositivos à rede Wi-Fi

💻 Opção B: Configurar em Cada Dispositivo

Windows

  1. Painel de Controle → Rede e Internet → Central de Rede e Compartilhamento
  2. Clique na sua conexão → Propriedades
  3. Selecione "Protocolo TCP/IP Versão 4" → Propriedades
  4. Marque "Usar os seguintes endereços de servidor DNS"
  5. Servidor DNS preferencial: 192.168.10.20
  6. Servidor DNS alternativo: 8.8.8.8
  7. OK → OK

macOS

  1. Preferências do Sistema → Rede
  2. Selecione sua conexão (Wi-Fi ou Ethernet) → Avançado
  3. Aba "DNS"
  4. Clique no botão + embaixo da lista de servidores DNS
  5. Digite: 192.168.10.20
  6. Arraste esse servidor para o topo da lista
  7. OK → Aplicar

Linux (Ubuntu/NetworkManager)

  1. Configurações → Rede
  2. Clique no ícone de engrenagem da sua conexão
  3. Aba "IPv4"
  4. Em "DNS", desative "Automático"
  5. Digite: 192.168.10.20
  6. Aplicar

iPhone/iPad

  1. Ajustes → Wi-Fi
  2. Toque no (i) ao lado da rede conectada
  3. Configurar DNS → Manual
  4. Remova os servidores existentes
  5. Adicionar Servidor: 192.168.10.20
  6. Salvar

Android

  1. Configurações → Wi-Fi
  2. Pressione e segure a rede conectada → Modificar rede
  3. Opções avançadas → Configurações de IP → Estático
  4. DNS 1: 192.168.10.20
  5. DNS 2: 8.8.8.8
  6. Salvar

✅ Depois da Configuração

Clique no botão abaixo para testar se está funcionando:

Se funcionar, acesse: http://reequilibrio.local/
